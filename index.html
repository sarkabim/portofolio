Tentang Saya,
Eksplorasi & Minat.

Saya adalah mahasiswa Program Studi Sistem Informasi semester 3 di Universitas Nusantara PGRI Kediri. Melalui kurikulum akademik dan eksplorasi mandiri, saya mendalami bagaimana teknologi informasi dapat dirancang untuk memecahkan masalah nyata pengguna.

Di luar jam kuliah, saya aktif berkembang bersama komunitas koding SIKOKI. Melalui forum diskusi, sesi berbagi kode, dan proyek bersama, saya terus mengasah kebiasaan kolaboratif serta memperluas wawasan praktik terbaik dalam pengembangan aplikasi web.

Fokus utama ketertarikan saya berada pada perpaduan Web Development dan UI/UX Design untuk menciptakan antarmuka digital yang nyaman, cepat, dan inklusif.
